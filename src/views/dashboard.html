Como interpretar
A nota operacional e os descontos são calculados pela API para o período selecionado. Quando houver mais de uma versão vigente, o detalhamento preserva cada peso por versão e não resume o período pelo peso mais recente. Alterações de pesos valem para novas apurações e não recalculam notas históricas.
