# Critical Points
- [x] CP1: A API de pesos retorna exatamente as cinco chaves novas e o endpoint de performance retorna pesos, deducoes reais, estacao e nenhum campo lento.
- [x] CP2: O dashboard carrega os cards de performance e abre um detalhamento com tabelas de ocorrencias ou mensagem de ausencia.
- [x] CP3: O detalhamento exibe as colunas Deducao e Estacao e o botao Fechar remove a selecao.
- [x] CP4: O modal de criterios mostra os valores vindos da API e a escala 4,5/3,5/2,5, sem criterios antigos.
- [x] CP5: A aba admin mostra cinco inputs preenchidos pelo GET e o PUT com minimo maior que maximo retorna 400.
- [x] CP6: As exportacoes Excel e PDF sao baixadas e o trecho do exportador nao contem a coluna Itens lentos nem deducoes sinteticas.
